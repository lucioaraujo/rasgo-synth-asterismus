Instalação

Sem assinatura digital paga (decisão do projeto RASGO): o Windows e o macOS mostram um aviso na primeira abertura — é esperado.

  • Windows

    Rode o instalador rasgo-synth-asterismus-0.3.0-win64.exe (ou use o .zip portátil).

    Se aparecer "O Windows protegeu o computador" (SmartScreen): Mais informações → Executar assim mesmo.

    O atalho fica no Menu Iniciar. O runtime do Visual C++ vai dentro do programa.

  • macOS (Intel e Apple Silicon, 10.15 ou mais novo)

    Abra o .dmg e arraste Rasgo Synth Asterismus para Aplicativos.

    Na primeira vez: botão direito no app → Abrir → Abrir (ou Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim).

    Se ainda recusar, no Terminal: xattr -dr com.apple.quarantine "/Applications/Rasgo Synth Asterismus.app"

  • Linux

    Pacote .deb: sudo apt install ./rasgo-synth-asterismus-0.3.0-Linux.deb — o atalho aparece em Som e Vídeo.

    Arquivo .tar.gz: extraia e rode usr/bin/rasgo-synth-asterismus.

  • Onde ficam as gravações

    ~/Music/Rasgo Synth Performance/recordings/ (uma pasta por tomada: a mistura em WAV de 24 bits, um WAV por estrela e o manifesto), os álbuns em albuns/ e o diagnóstico em diagnostico/.
