Installation

No paid code signing (a RASGO project decision): Windows and macOS show a warning the first time — it is expected.

  • Windows

    Run the installer rasgo-synth-asterismus-0.3.0-win64.exe (or use the portable .zip).

    If "Windows protected your PC" (SmartScreen) appears: More info → Run anyway.

    The shortcut is in the Start menu. The Visual C++ runtime is inside the program.

  • macOS (Intel and Apple Silicon, 10.15 or newer)

    Open the .dmg and drag Rasgo Synth Asterismus to Applications.

    The first time: right-click the app → Open → Open (or System Settings → Privacy & Security → Open Anyway).

    If it still refuses, in Terminal: xattr -dr com.apple.quarantine "/Applications/Rasgo Synth Asterismus.app"

  • Linux

    .deb package: sudo apt install ./rasgo-synth-asterismus-0.3.0-Linux.deb — the shortcut appears in Sound & Video.

    .tar.gz archive: extract it and run usr/bin/rasgo-synth-asterismus.

  • Where the recordings go

    ~/Music/Rasgo Synth Performance/recordings/ (one folder per take: the mix as a 24-bit WAV, one WAV per star and the manifest), albums in albuns/ and the diagnostics in diagnostico/.
