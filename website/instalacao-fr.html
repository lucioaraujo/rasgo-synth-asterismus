Installation

Sans signature payante (décision du projet RASGO) : Windows et macOS affichent un avertissement à la première ouverture — c'est attendu.

  • Windows

    Lancez l'installeur rasgo-synth-asterismus-0.3.0-win64.exe (ou utilisez le .zip portable).

    Si « Windows a protégé votre ordinateur » (SmartScreen) apparaît : Informations complémentaires → Exécuter quand même.

    Le raccourci est dans le menu Démarrer. Le runtime Visual C++ est dans le programme.

  • macOS (Intel et Apple Silicon, 10.15 ou plus récent)

    Ouvrez le .dmg et glissez Rasgo Synth Asterismus dans Applications.

    La première fois : clic droit sur l'app → Ouvrir → Ouvrir (ou Réglages Système → Confidentialité et sécurité → Ouvrir quand même).

    S'il refuse encore, dans le Terminal : xattr -dr com.apple.quarantine "/Applications/Rasgo Synth Asterismus.app"

  • Linux

    Paquet .deb : sudo apt install ./rasgo-synth-asterismus-0.3.0-Linux.deb — le raccourci apparaît dans Son et vidéo.

    Archive .tar.gz : extrayez-la et lancez usr/bin/rasgo-synth-asterismus.

  • Où vont les enregistrements

    ~/Music/Rasgo Synth Performance/recordings/ (un dossier par prise : le mixage en WAV 24 bits, un WAV par étoile et le manifeste), les albums dans albuns/ et le diagnostic dans diagnostico/.
